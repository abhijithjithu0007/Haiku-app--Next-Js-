# Haiku App

A simple **Haiku Generator** built with Next.js. This app creates traditional 5-7-5 syllable haikus with ease. Perfect for poetry lovers and developers!

## Features
- Generates random haikus.
- Clean and responsive design.
- Built with Next.js for fast performance.
